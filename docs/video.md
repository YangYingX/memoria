# B站视频采样

视频采样是自主浏览的一部分。启用后，她在随机空闲机会选择去B站时，仍先按兴趣选择视频、读取可用文字，再按配置处理部分画面和语音。你也可以在聊天中发完整的 `https://www.bilibili.com/video/BV…/` 链接；默认使用第一P，支持链接中的 `?p=2` 等明确分P。后台用于调整能力和预算，无须反复点击执行。

## 准备本地处理

在项目目录执行：

```bash
npm run video:prepare
```

需要 Node.js 22.16+，目前自动下载支持 Windows x64 与 Linux glibc x64。准备命令下载固定版本的 LGPL FFmpeg/ffprobe，核对归档校验值、解码能力和许可资料，写入本机 `data/video-runtime.json`；不安装到系统目录。重复执行会校验并复用已有工具。使用其他数据目录时可加 `-- --data-dir /绝对/数据目录`。

也可自行准备工具，使用 `npm run video:prepare -- --ffmpeg /绝对/ffmpeg路径 --ffprobe /绝对/ffprobe路径` 核验；工具需要具备 MP4、H264、AAC、JPEG 与 PCM/WAV 能力。运行层只接受本机数据，不让模型选择命令、参数或媒体下载地址。

如需语音转写，另按[本地语音输入](voice.md)准备 SenseVoice。视频和QQ语音共用本地识别资源；模型按需加载，识别本身不调用云端API。识别文字可能有误，不能据此判断音乐、音色或音效的含义。

## 配置与实际覆盖

在“人格与设置”的 B站区域开启画面与语音采样：

- 每个视频默认均匀抽取6张画面，最多8张；设为0可关闭画面理解。画面交给配置的图片输入模型，最多增加一次模型请求，计入已有每日模型额度。
- 有可用A1字幕时不重复转写；无字幕或只有平台文字时，最多转写开头60秒。设为0可关闭转写。
- 媒体下载默认每天256 MiB，转写默认每天360秒，均可调整。按UTC日期计数，重启、换会话或保存配置不清零。
- 每轨最多64 MiB、同一视频合计最多96 MiB。下载前保守预占每轨64 MiB，失败也不退还。每个视频只尝试一次媒体增强，不自动重试失败的采样。

平台资料读取与媒体预算分别计算；公开评论、发帖仍使用既有公开操作限额。模型与平台可能不支持某种内容，登录、权限检查或验证码也可能阻止读取；不尝试绕过这些限制。

遇到平台要求验证或限制访问时，媒体采样会暂停，重启或跨日不会自动恢复。请先在B站官方页面核验，再在设置页点击“已完成官网核验，恢复媒体采样”。恢复不会清零已用额度，也不会立即执行浏览任务。

图片输入需要模型服务实际支持。例如可使用支持视觉输入的 DeepSeek Flash，或自行配置兼容的多模态服务；不要仅凭模型名称认定所有服务都支持图片。无图片能力时可把画面数设为0，保留可用文字和本地语音转写。

这是部分内容理解：采样会漏掉快速画面，开头60秒以外的声音未处理，本版不会自动续读长视频。书架记录区分字幕、平台文字、画面时点观察和机器语音转写，并保留来源分P、CID、模型与样本校验值；这些记录不代表完整观看。后续笔记、聊天和评论只能依据实际取得的范围。画面与音轨原始文件仅用于当前任务，不进入记忆、备份或源码。
