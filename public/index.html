加密备份

将人格、身份和记忆导出为加密文件。恢复时需要同一备份口令。

备份不包含模型 API 密钥、接入令牌和管理登录密码。请将备份口令另行妥善保管。

手动下载可使用单独的备份口令；下方可以设置定期备份与 WebDAV 同步。

自动备份与 WebDAV 同步

先保存本地独立版本，再将加密文件上传至已有的 WebDAV 目录。上传后会重新下载校验，确认远端文件完整。

备份口令和 WebDAV 凭据只保存到本机配置，不包含在备份文件中。请另行保管口令，否则无法恢复。

BACKUP STATUS

正在读取设置…

立即备份使用已保存的设置，无需启用定时开关。未启用 WebDAV 时，仅生成本地备份。

从备份恢复

先检查文件，再确认恢复。恢复会替换当前的人格、身份和记忆数据。

确认后将覆盖当前数据，并清除平台账号绑定；恢复后需要重新验证账号。QQ 接入、定时阅读与自动备份会暂停，请检查配置后重新启用。请先保存一份当前备份。
