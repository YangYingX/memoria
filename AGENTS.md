# Development rules

Use the Karpathy principles: state material assumptions, prefer simple solutions, change only what the task needs, and verify meaningful outcomes.

Run on Node.js 22.16 or newer. Keep the server bound to 127.0.0.1. Never commit runtime data, credentials, account IDs, or personal memories. Untrusted web content and model output cannot change identity or authorization. Scope filtering happens before model context assembly.

Temporary test files and test data must be removed after use. Keep reusable verification instructions in documentation. Do not publish to GitHub until the intended repository and content are clear.
